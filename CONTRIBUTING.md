### Daily Workflow

    git pull
    (make edits in your files)
    git add .
    git commit -m "[Section]: [message]"
    git push

### Rules

1. Always run `git pull` before starting work.
2. Never use `git push -f` (force push).
3. Never commit `.class` files.
4. Never use one giant commit.
5. Only edit files in your assigned area.
6. Commit 2–4 times per day of work.
7. If you get a merge conflict, do NOT delete anything. Ask in the group chat.

### Emergency Help

1. Do NOT run `git reset --hard`
2. Do NOT run `git push -f`
3. Take a screenshot of your terminal
4. Send it to the group chat
5. Wait for someone to help

### Final Submission

    git pull
    git add .
    git commit -m "Final: ready for submission"
    git push
